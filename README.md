## Features:-
1. You can bet virtual money!
2. ASCII art as mentioned above!
3. A cheeky dealer (who is the devil himself)
4. Three Secret words, 'devil', 'lucifer', 'tangiers' (it doesn't really do anything js give you an extra line)

## How to Run
### Prerequisites
Python 3.x installed on your system.

### Running the Game
1. Clone or download the repository

2. Open your terminal or command prompt.

3. Navigate to the folder containing the script.

4. Run the game using:

``` bash
python blackjack.py
```
***OR***
Use the exe file from the releases section (much better that way P.S. that can only run on windows)
